# EV3 Bot Eyes

A standalone React 19 library for giving eyes to agents and apps. Two SVG eyes
follow the cursor as one invisible head, blink naturally, and perform ten
expressive reactions. Includes six shapes, independent eye/halo colors, and
outward edge blur that never shrinks the solid eyes.

Only React is a runtime peer dependency. No Tailwind, EV3 CSS tokens, router,
Tauri, backend, or application-level event bus is required. Nothing writes to
storage or performs an application action automatically.

## Develop and package

Requires Node 20.19+ and npm.

```sh
npm ci
npm run typecheck
npm test
npm run dev             # standalone playground at http://127.0.0.1:5174
npm run build:demo      # demo-dist/
npm pack               # umunnu-ev3-bot-eyes-0.1.0.tgz
```

Re-run `npm run build` after library source changes while the demo is running.

The package is built as ESM and CommonJS with TypeScript declarations, source
maps, and separate pure geometry/animation entry points. Build output lives in
`dist/` and is generated by `npm run build` or `npm pack`.

## Install in another app

Create the archive with `npm pack` in this repository, then install its path in
your React app (React must be installed by the app):

```sh
npm install /path/to/umunnu-ev3-bot-eyes-0.1.0.tgz
```

The package has not been published to npm by this extraction. EV3 consumes a
versioned archive under its own `vendor/` directory, so a fresh EV3 checkout does
not depend on this repository being in a particular sibling folder.

```tsx
import { useRef } from 'react';
import { CuriousEyes, type CuriousEyesHandle } from '@umunnu/ev3-bot-eyes';

export function AgentAvatar() {
  const eyes = useRef<CuriousEyesHandle>(null);
  return (
    <div>
      <CuriousEyes
        ref={eyes}
        size={96}
        appearance={{
          shape: 'rectangle', width: 15, height: 22, rounding: 85,
          color: '#29e8ed', edgeBlur: 0.6, blurColor: '#08a6bd',
        }}
      />
      <button onClick={() => eyes.current?.play('dance')}>Celebrate</button>
    </div>
  );
}
```

## Component API

| Prop | Default | Meaning |
| --- | --- | --- |
| `appearance` | default appearance | Partial appearance; omitted fields use defaults. |
| `size` | `52` | SVG width/height attributes; number or CSS-compatible SVG length. |
| `className`, `style` | unset | Host styling. CSS width/height can override `size`. |
| `animated` | `true` | Cursor tracking and natural blinking. A still instance can explicitly play a reaction. |
| `ref` | unset | `play(id): boolean`, `stop(): void`. React 19 ref prop. |
| `onAnimationEnd` | unset | Called on completion, stop, replacement, or visibility/reduced-motion cancellation; not unmount. |

The SVG is decorative (`aria-hidden`, not focusable, no pointer interception).
Put an accessible label on its surrounding button or avatar when appropriate.
The default inline styles supply its layout, transparent backdrop, and visible
halo overflow. A containing element with `overflow: hidden` can still clip the halo.

### Appearance

| Field | Default | Meaning |
| --- | --- | --- |
| `shape` | `rectangle` | `rectangle`, `triangle`, `diamond`, `circle`, `hexagon`, `drop`. |
| `width`, `height` | `13`, `18` | Solid eye dimensions in SVG units. |
| `gap` | `7` | Clear space between unrotated solid eyes. |
| `rounding` | `85` | Shape-specific rounding, 0–100. Diamond sides curve inward; circle is already round. |
| `rotation` | `0` | Degrees, mirrored between eyes. |
| `color` | `#000000` | Any valid CSS color, including host CSS variables. |
| `edgeBlur` | `0` | 0–1; halo grows outside the solid eye size. |
| `blurColor` | `null` | Any CSS color; null follows the eye color. |

`defaultCuriousEyesAppearance` and `curiousEyesPalette` are exported conveniences.
Palette values are literal colors; apps may supply their own design tokens.
Slider ranges in the playground are examples, not a persistence schema.

### Reactions

`hello`, `celebrate`, `scared`, `alert`, `thinking`, `sleepy`, `skeptical`, `oops`,
`dizzy`, and `dance`. `curiousEyesAnimations` includes names, descriptions,
suggested scenarios and durations. Reactions are one-shot; `play` replaces an
active reaction and returns false when motion is unavailable. Apps choose which
real actions trigger them and can repeat thinking while work remains pending.

Pointer tracking is smoothed, touch does not steer the gaze, and losing focus
returns it to center. Hidden/offscreen eyes and reduced motion stop animations.
Unmount removes listeners and cancels timers/frames. The renderer does not
rerender React on each animation frame. Appearance changes preserve the pose.

### Pure exports

```ts
import { eyeShapePath, eyeViewBox } from '@umunnu/ev3-bot-eyes/geometry';
import { sampleEyesAnimation, animationDuration } from '@umunnu/ev3-bot-eyes/animations';
```

The same utilities and types are also exported from the main entry point.
Geometry and pose sampling do not require React or a browser. Canvas and pose
fitting consider the solid shapes only; the halo uses a larger filter region.

## EV3 integration and updates

EV3's adapters preserve its existing component imports, CSS sizing, palette
variables, and saved appearances. App-local persistence and delete/notification/
loading/completion events remain in EV3. The renderer, geometry, and animations
have one implementation in this repository.

For a library update, change its version, run its checks, pack it, copy the archive
to EV3's `vendor/`, and update EV3's dependency/lockfile using `npm install`.
Verify EV3's Showcase and `node --test tests/logo-feedback.test.cjs` as well as
its typecheck and frontend build. Do not publish, push, or change licensing as
part of routine extraction work without the owner's instruction.
